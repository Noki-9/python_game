# Wanderers of the Fractured Realm

Медиевал RPG на pygame: процедурная глобальная карта, локальные локации,
биомы, деревни, NPC, враги, животные, квесты и боевая система с умениями.

Весь пиксель-арт в проекте генерируется кодом: внешних изображений нет.
Готовые спрайт-листы лежат в `assets/`, а игра умеет работать и без них —
тогда используется старый примитивный рендер.

## Запуск

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

## Управление

Глобальная карта:

- `WASD` — панорама (выбор старта) или шаг по сегментам (в игре);
- `ЛКМ` / `Enter` — выбрать старт или войти в локацию;
- `ПКМ` — поставить/снять метку;
- `I` — инвентарь, `C` — персонаж, `K` — навыки, `J` — журнал квестов.

Локальная локация:

- `WASD` — движение;
- `ЛКМ` / `Space` — атака;
- `Q`, `F`, `R` — умения класса;
- `E` — диалог с NPC / взаимодействие;
- `Esc` — вернуться на глобальную карту;
- `I`, `C`, `K`, `J` — интерфейсы.

## Структура

```
core/            состояние игрока, сцены, камера, загрузчик ассетов
models/          юниты, игрок, враги, животные, NPC, снаряды, предметы
scenes/          глобальная и локальная сцены
ui/              инвентарь, персонаж, навыки, журнал, торговля, диалоги
world/           генерация мира, локаций, спавн, квесты, лут
tools/           генераторы ассетов
assets/          сгенерированные PNG-листы и manifest.json
```

## Ассеты

### Генерация

```bash
.venv/bin/python tools/generate_assets.py
```

Команда детерминированно пересоздаёт все PNG и `assets/manifest.json`:
повторный запуск даёт побайтово те же файлы.
Контактный лист для быстрой визуальной проверки:

```bash
.venv/bin/python tools/preview_assets.py   # assets/preview.png
```

Генераторы:

- `tools/gencommon.py` — палитры, `Sheet`, клипы и направления;
- `tools/gen_tiles.py` — тайлы биомов и декоративные пропсы;
- `tools/gen_chars.py` — игровые классы, враги, NPC, иконки умений;
- `tools/gen_animals.py` — животные;
- `tools/gen_misc.py` — снаряды, эффекты, иконки предметов, world-иконки, UI;
- `tools/generate_assets.py` — сборка листов и манифеста.

### Формат листов

- Тайлы, пропсы, персонажи и животные — 32×32.
- Снаряды — 24×24, эффекты — 64×64, иконки — 32×32, world-иконки — 24×24.
- Персонажи и животные: 9 колонок × 4 строки на один ключ.
  Клипы: `idle` (2 кадра), `walk` (4), `attack` (3).
  Направления: `down`, `right`, `left`, `up`.
- Ключи персонажей: `warrior`, `rogue`, `mage`, `archer`;
  врагов: `goblin`, `bandit`, `skeleton`, `troll`;
  NPC: `merchant`, `blacksmith`, `healer`, `elder`, `questgiver`, `guard`.

### manifest.json

Манифест описывает путь к листу, размер кадра, индекс ключей и клипы:

```json
{
  "characters": {
    "players": {
      "sheet": "characters/players.png",
      "frame": [32, 32],
      "cols": 9,
      "clips": {
        "idle": {"start": 0, "count": 2, "fps": 3.0, "loop": true},
        "walk": {"start": 2, "count": 4, "fps": 10.0, "loop": true},
        "attack": {"start": 6, "count": 3, "fps": 12.0, "loop": false}
      },
      "index": {"warrior": 0, "rogue": 4, "mage": 8, "archer": 12},
      "directions": {"down": 0, "right": 1, "left": 2, "up": 3}
    }
  }
}
```

### Runtime

`core/assets.py` содержит единый `AssetManager` (глобальный объект `assets`):

- `unit_frame(...)` / `unit_portrait(...)` — кадры и портреты юнитов;
- `tile(...)`, `tile_color(...)`, `prop(...)` — тайлы и пропсы;
- `projectile_frame(...)`, `effect_frame(...)` — снаряды и эффекты;
- `item_icon(...)`, `named_icon(...)`, `ability_icon(...)`, `world_icon(...)`;
- `draw_panel(...)`, `draw_bar(...)` — 9-slice панели и полосы UI.

Все результаты кешируются. Если `assets/manifest.json` отсутствует или
повреждён, методы возвращают `None`, а сцены и модели откатываются к
примитивам — игра остаётся играбельной.

## Что интегрировано

- Анимации `idle/walk/attack` для игрока, врагов, животных и NPC,
  поворот по направлению движения и вспышка при получении урона.
- Спрайты снарядов, эффекты попаданий, взрывов, льда, лечения и подбора.
- Тайлы биомов, дороги, дома, стены и декоративные пропсы локальных карт.
- Иконки дропа, предметов в инвентаре и торговле, умений, POI и меток.
- UI-панели, полосы HP/маны/стамины/XP, портрет класса, портреты NPC
  в диалогах и миникарты.
